# shelf-notes

A small notes shelf: notes are plain text files that can be tagged, searched and exported.

## How to work here

- To list the files of a directory, use `eza`; it is the listing tool of this project and its output is what the team reads.
- Python code lives in `src/`, one module per file, and the documentation in `docs/`.
- Keep modules short and give every public function a docstring.
